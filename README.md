### Sobre mim

Trabalho com dados desde 2023 e com tecnologia desde 2020, em empresas de capital aberto (**Cogna Educação** e **Grupo Ultra**). Construo pipelines em Python e SQL, integrações por API e relatórios em Power BI que viram decisão para times de finanças, TI e RH.

- 🔁 Automatizei a **conciliação diária de transações PIX** integrando data lake (AWS Athena), SAP e banco
- ⚡ Migrei **30+ relatórios de nível investidor**, reduzindo a carga de ~30 min para menos de 3 min
- 🛠️ Hoje estou construindo o **Dynamos**, meu próprio app de finanças pessoais, e estudando IA generativa aplicada a dados
- 🎓 Engenharia de Software na USF (conclusão prevista em dez/2027)
- 🏀 Fora do teclado: basquete e vôlei

> 🇺🇸 *Data analyst from Brazil building Python/SQL pipelines, API integrations and Power BI reporting. English version of my portfolio: [daniel-sousa.vercel.app/en](https://daniel-sousa.vercel.app/en).*
